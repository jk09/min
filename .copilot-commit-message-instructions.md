# The `git` commit message instructions

The commit message should consist of:

  1. Header in the format <type>(<scope>): <description>. Examples of `<type>`: `feat`, `chore`, `fix`, `docs`, `refactor`, `revert`, etc.
  2. Reference to the _specification_ file in the  [spec folder](spec/) used as a context for the agentic run, if any. The path to the specification file should only contain the invariant parts, without workflow folders such as `in_progress`, `backlog`, etc. Example:
    - `feat-q4m8zt-prompt-command-runtime\SPEC.md` - OK
    - `spec\in_progress\feat-q4m8zt-prompt-command-runtime\SPEC.md` - WRONG
  3. The summary of the agentic run in the Markdown format. Preferably the summary generated by the agent itself.
