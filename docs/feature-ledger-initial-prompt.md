being aware of features already implemented
only the most up-to-date variant of any feature should be considered
do not consider features which have been part of the application, but have been superseded or abandoned

have an up-to-date documentation of all times
context of existing features for each agentic run
after each agentic run the existing features should be verified by tests, unless having been superseded by the current agentic run
